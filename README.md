# ألوان سهلة — Easy Palette

تطبيق مجاني يساعدك على اختيار ألوان متناسقة بدون أي خبرة في التصميم (عربي + إنجليزي).

## كيف أشغّل التطبيق؟
1. حمّل المشروع إلى جهازك (من GitHub: زر **Code** ثم **Download ZIP**، ثم فك الضغط).
2. افتح ملف `index.html` بنقرتين. سيفتح في المتصفح مباشرة.

لا تحتاج تثبيت أي برنامج.

## كيف أنشره على الإنترنت مجاناً؟
- **Netlify:** افتح https://app.netlify.com/drop واسحب مجلد المشروع إلى الصفحة.
- أو **GitHub Pages:** من إعدادات المستودع ← Pages ← اختر الفرع الرئيسي.

## أين أجد ماذا؟
| الملف | ماذا يحتوي |
|---|---|
| `js/i18n.js` | كل النصوص بالعربية والإنجليزية (عدّل الكلمات من هنا) |
| `js/palettes.js` | اللوحات الجاهزة والأقسام الأربعة |
| `css/style.css` | الشكل والتصميم |
| `js/app.js` | الشاشات والتنقل |
| `CLAUDE.md` | المواصفات الكاملة وخطة المراحل |
